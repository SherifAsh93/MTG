# Contigoo Studio — QA test cases

Generated from the executable QA definitions. Source: `qa-tools/model-cases.mjs`, `browser-cases.mjs`, `pending-cases.mjs`.

## Scope and environment

- Tested application baseline: `7b1d376c2563b61fbd433a435c4e3cf25c14bd9c` (clean working tree).
- 144 additional executable cases: 81 model, 63 browser; 33 explicitly deferred cases. The existing 48-check regression suite and static/live smoke tests are separate evidence.
- Covers current operations with positive, negative, boundary, persistence, dependency, safe-rendering and responsive cases. This is risk-based coverage of this build, **not proof that every possible input/combination or future feature has been tested**.
- Browser cases use isolated contexts and synthetic data on an ephemeral loopback server. Real owner/customer records and credentials are never loaded.
- Generic CRUD for every built-in module is tested; that is not verification of native mobile packaging, financial/stock engines, login or production isolation.
- Execution results: `QA_EXECUTION_REPORT.md`; timestamped JSON/screenshots under `qa-tools/results/`.
